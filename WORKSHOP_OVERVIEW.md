# Workshop Overview

## Purpose

**ChatGPT for Software Architects** teaches architects and senior developers how to use generative AI across the complete architecture lifecycle.

The workshop combines:

- **Reasoning AI** for understanding, design, trade-offs, and decisions.
- **Repo-aware engineering AI** for analysis, implementation planning, refactoring, testing, and governed change.

## Six Acts

### Act 1 — THINK
Discover the architecture problem.

Topics:
- business outcomes
- personas
- customer journeys
- pain points
- functional requirements
- NFRs
- assumptions
- unknowns

### Act 2 — DESIGN
Build the architecture.

Topics:
- workload modeling
- capability decomposition
- service boundaries
- data ownership
- integration patterns
- failure modeling
- graceful degradation

### Act 3 — DECIDE
Make defensible architecture decisions.

Topics:
- alternatives
- trade-offs
- decision matrices
- evidence
- reversibility
- risk
- ADRs
- validation metrics

### Act 4 — DELEGATE
Turn architecture intent into repo-aware engineering.

Topics:
- Claude Code
- repository discovery
- `CLAUDE.md`
- plan-first workflows
- architecture katas
- bounded refactoring
- characterization tests

### Act 5 — GOVERN
Govern AI-generated engineering work.

Topics:
- VIBE → GEAR
- ARCH-GATE
- ALLOW / ASK / DENY
- MCP security
- prompt injection
- secrets
- approval boundaries

### Act 6 — OPERATE
Use production evidence to evolve architecture.

Topics:
- architecture fitness functions
- observability
- architecture drift
- degraded modes
- incident learning
- ADR updates
- continuous architecture

## Participant Outcome

Participants should leave able to answer:

1. What problem are we solving?
2. What architecture should exist?
3. Why did we choose this design?
4. How do we safely delegate implementation work to AI?
5. How do we review and govern AI-generated change?
6. How do we know whether the architecture is still working in production?

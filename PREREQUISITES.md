# Prerequisites

## Recommended Audience
- Software architects
- Solution architects
- Enterprise architects
- Staff / principal engineers
- Senior developers
- Tech leads
- Engineering managers

## Knowledge
Basic understanding of:
- software architecture
- APIs
- databases
- cloud systems
- distributed systems
- testing
- Git

Advanced AI knowledge is not required.

## Accounts / Tools
Recommended:
- ChatGPT account
- GitHub account
- Git installed
- IDE/editor
- Claude Code access for repo-aware exercises

## Before the Workshop
Be comfortable:
- cloning a Git repository;
- reading application code;
- running tests locally;
- discussing architecture trade-offs.

Do not use production credentials, customer data, or confidential company information.
